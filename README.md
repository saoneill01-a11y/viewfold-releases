A fast, simple picture and video viewer for the Mac.

Requires macOS 15 or later. Signed and notarized by Apple.

## Features

- Opens pictures from Finder and flips through the whole folder with the arrow keys
- Smooth zoom and pan, full screen
- Thumbnail grid that stays fast with thousands of pictures, with a folder sidebar
- Videos and Live Photos
- Map view of where pictures were taken
- Remembers thumbnails, so folders you've seen open instantly, even on network drives
- Checks for updates by itself
- JPEG, PNG, HEIC, GIF, TIFF, BMP, WebP and camera RAW

## Installing

1. Download and open **Viewfold.dmg**.
2. In the window that opens, drag **Viewfold** onto the **Applications** folder.
3. Open it. The first time, macOS asks if you're sure you want to open an app downloaded from the internet; click **Open**.

To update, do the same: drag the new Viewfold onto Applications and choose **Replace**. Viewfold tells you when a new version is out.

To make Viewfold your default viewer: in Finder, select a picture, press Cmd+I, choose Viewfold under **Open with**, and click **Change All**.
